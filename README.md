# puter-js-chatgpt-free-ui
A lightweight mobile-friendly ChatGPT clone built with HTML, CSS, and JavaScript, powered by Puter.js AI APIs. It features live streaming responses, syntax-highlighted code blocks with copy button, dark/light theme toggle, and a smooth mobile-optimized UI.


## 🚀 Features

- Real-time AI streaming responses (via puter.ai.chat)
- Prism.js syntax highlighting for Python, JavaScript, and HTML
- Copy to clipboard button inside code blocks
- Dark/Light theme toggle 🌗
- Auto-scroll with scroll-to-bottom button
- Mobile-optimized design with smooth scrolling
- Typing indicator animation while waiting for responses
- Error handling with graceful fallback messages

## 🔧 Setup

1. Clone or download this repository.

```
git clone https://github.com/your-username/puter-chatgpt-mobile-clone.git
cd puter-chatgpt-mobile-clone
```
2. Open index.html directly in your browser OR serve it locally:
```
# Python
python -m http.server 8080
# Node.js
npx serve
```

3. Visit:
```
http://localhost:8080
```

## 🛠️ Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- AI Backend: Puter.js AI API
- Syntax Highlighting: Prism.js
